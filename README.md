# MEDPHYS — физика в медицине

Статический учебный прототип, который публикуется через GitHub Pages из каталога `docs`.

## Публикация на GitHub Pages

1. Загрузите содержимое каталога `docs` в каталог `docs` репозитория.
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**.
4. Branch: `main`; Folder: `/docs`; нажмите Save.
5. После публикации откройте `https://<ваш-профиль>.github.io/MEDPHYS/`.

## Что работает в прототипе

- Навигация по разделам и адаптивная мобильная панель.
- Каталог учебных тем с локальной отметкой изучения.
- Виртуальная лаборатория: модель центрифуги и расчёт центростремительного ускорения; модель равномерного движения и расчёт пути.
- Тренировочный вопрос с проверкой ответа.
- Поиск по словарю терминов.
- Локальное сохранение прогресса и базовый Service Worker для офлайн-кэша.

## Важно

Это демонстрационный каркас, а не готовый аккредитованный курс. Состав тем, формулировки, учебные часы, лекции и задания необходимо согласовать с рабочей программой медицинского колледжа. Прогресс хранится только в браузере данного устройства; серверной авторизации и синхронизации пока нет.

Внешний шрифт загружается из Google Fonts при наличии интернета; при офлайн-доступе используется системный запасной шрифт.
